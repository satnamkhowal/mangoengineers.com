# Mango Engineers — Agent Start Here

1. Pull/read latest main and recent commits.
2. Read AGENTS.md, docs/task-board.csv, docs/work-log.md and docs/integration-queue.md.
3. Inspect the exact files/URLs for the task before changing code.
4. Confirm the task is UNCLAIMED or explicitly assigned to your branch.
5. Keep work isolated. Shared header/footer/CSS/JS/forms/schema/redirect/sitemap changes belong in the integration queue unless your task explicitly owns them.
6. Reuse the current theme and shared PHP architecture.
7. Preserve working/indexed URLs. Do not create duplicate SEO intent.
8. Use verified business facts only. Do not publish template/demo claims as Mango Engineers facts.
9. Run relevant checks before moving a task to REVIEW.
10. Record branch, commit, files/URLs and remaining issues.

## Statuses
UNCLAIMED, CLAIMED, IN_PROGRESS, REVIEW, NEEDS_FIX, BLOCKED, INTEGRATION_REQUIRED, DONE.

## Completion states
IMPLEMENTED -> MERGED -> DEPLOYED -> LIVE VERIFIED are separate. Never collapse them.
