## Recommended action

### P0/P1 — Verify branch truth first
Before creating or optimizing branch/location pages, verify:
- which branches are currently operational
- exact business name on signage/profile
- address formatting
- primary phone
- opening hours
- current Google Business Profile URL/ID
- whether older Mansarovar details are historical and should be removed

Until verified, local page creation status = **NEEDS VERIFICATION**.

### P1 — Genuine branch pages, only if verified
If Tonk Phatak / Shri Kishanpura / Shyam Nagar are real current branches, one useful page per real branch can be justified.

Each branch page should contain:
- exact verified NAP
- map/profile link
- courses available at that centre
- classroom/online availability
- counselling/visit process
- nearby transport/landmark guidance that is actually accurate
- unique branch photos if rights are available
- branch-specific FAQs
- links to core course pages
- LocalBusiness/EducationalOrganization structured data only when the entity details are verified

Do not create dozens of city/neighborhood swap pages.

### P2 — Jaipur hub
The existing course catalogue / homepage can target broad Jaipur IT-training intent and route users to commercial course pages. A separate “IT Training Institute in Jaipur” landing page is only justified if it provides materially different decision content and does not cannibalize the homepage/course catalogue.

Current recommendation: **IMPROVE existing hub before creating a new Jaipur generic page**.

## Doorway-page guardrail

Google’s spam policies specifically warn against substantially similar pages targeted at many regions/cities that funnel users to one destination. Mango should use real branch pages and useful Jaipur-specific content, not mass locality variants:
https://developers.google.com/search/docs/essentials/spam-policies
